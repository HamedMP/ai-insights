# Hindsight plugin

Look back at how you work with AI coding agents. Local insights and actionable tips from your Claude Code, Codex, Cursor, Pi and OpenCode history.

Claude Code:

```
/plugin install hindsight --marketplace hamedmp/hindsight
```

Codex:

```
codex plugin marketplace add hamedmp/hindsight
codex plugin add hindsight@hindsight
```

This is the installable plugin for Claude Code and Codex. It is generated from `skills/` and `scripts/generate-harness.mjs` in https://github.com/hamedmp/hindsight; do not edit it by hand.
