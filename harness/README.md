# Generated harness output

`hindsight/` is generated by `node scripts/generate-harness.mjs` from `skills/`, `package.json` and the config at the top of that script. Do not edit it by hand.

Claude Code and Codex install `hindsight/` through `.claude-plugin/marketplace.json` and `.agents/plugins/marketplace.json`. Cursor and Pi use the repository root (`.cursor-plugin/plugin.json`, the `pi` block in `package.json`).

After changing a skill, the version or the config, run `node scripts/generate-harness.mjs` and commit the result. CI runs it with `--check`.
