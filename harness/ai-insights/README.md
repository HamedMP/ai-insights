# AI Insights plugin

Look back at how you work with AI coding agents. Local insights and actionable tips from your Claude Code and Codex history.

Claude Code:

```
/plugin marketplace add hamedmp/ai-insights
/plugin install ai-insights@ai-insights
```

Codex:

```
codex plugin marketplace add hamedmp/ai-insights
codex plugin add ai-insights@ai-insights
```

This is the installable plugin for Claude Code and Codex. It is generated from `skills/` and `scripts/generate-harness.mjs` in https://github.com/hamedmp/ai-insights; do not edit it by hand.
